# 한국어 다듬기

요청한 범위에서 어색하거나 잘못된 부분만 고친다. 자연스러운 문장은 그대로 두고, 사용자가 지정한 독자·용도·말투·수정 강도를 우선한다. 별도 요청이 없으면 원문의 격식과 문체를 유지한다.

## 의미와 정보 보존

- 사실, 수치, 단위, 날짜, 고유명사와 전문용어를 보존한다. 근거, 경험, 감정이나 새로운 주장을 만들어 넣지 않는다.
- 조건·예외·부정·시제·행위 주체와 가능성·확신의 정도를 유지한다. ‘할 수 있다’를 단정으로 바꾸거나, 피동을 고치면서 주체를 임의로 정하지 않는다.
- 직접 인용, 규정·계약의 인용문, 코드 블록, 인라인 코드, URL과 식별자는 수정하지 않는다. 해당 부분 자체의 교정을 명시적으로 요청받으면 요청 범위만 다룬다.
- 표의 수치·키·상태값은 보존한다. 설명 문장은 요청 범위에 포함되면 다듬되 표 구조와 연결 관계를 유지한다.
- 의미가 모호하면 추측해서 확정하지 않는다. 표현을 유지하거나 필요한 확인 사항만 짧게 알린다.

## 편집 기준

- 맞춤법·띄어쓰기·문법과 주어·서술어의 호응을 확인한다. 복수 표기가 허용되면 오류로 단정하지 말고 문서 안의 일관성을 따른다.
- 이중 피동, 긴 명사 나열, 불필요한 경동사와 반복 표현을 문맥에 맞게 줄인다. ‘검토를 진행했다’는 ‘검토했다’처럼 고칠 수 있다.
- 번역투와 상투적인 도입·마무리, 과장된 수식, 불필요한 접속사를 줄인다. 특정 단어나 표현을 금지어처럼 일괄 삭제하지 않는다.
- 전문용어는 독자와 용도에 맞게 유지한다. 같은 대상을 가리키는 용어를 불필요하게 바꾸어 쓰지 않는다.
- 목록·표·제목·개조식이 읽기에 도움이 되면 유지한다. 문장을 무조건 짧게 자르거나 리듬을 위해 어미를 억지로 섞지 않는다.
- 강조·이모지·문장부호는 용도에 맞게 정리한다. 쉼표나 특정 표현 하나만으로 작성 주체를 판정하지 않는다.
- ‘맞춤법만’ 같은 제한이 있으면 그 범위를 넘겨 문장이나 구조를 다시 쓰지 않는다. 문체 변경은 요청받았을 때만 한다.

## 확인과 출력

- 수정문을 원문과 대조해 정보 누락, 새 주장, 의미 변화가 없는지 확인한다. 더 자연스러워졌어도 의미가 달라졌다면 해당 수정을 되돌린다.
- 기본 출력은 수정문만 제공한다. 변경 설명은 요청받았을 때 덧붙이고, 의미를 확정할 수 없었던 부분은 필요한 경우 짧게 알린다.
- 불필요한 진단 점수, 변경률, 패턴 목록이나 숨겨진 주석을 붙이지 않는다. 글자 수 제한이 있으면 실제로 세어 확인한다.
- 교정할 부분이 없으면 원문을 유지한다. 탐지기 통과나 작성 주체 판별을 보장하지 않는다.
